# 🚗 PalGate × Grok — פתיחת שער בקול מהטסלה

שרת פרטי קטן (Cloudflare Worker, חינמי) שמחבר את חשבון ה-PalGate שלך
ומאפשר לפתוח את השער ב:

| דרך | איך |
|---|---|
| **Grok בטסלה** | "היי Grok, פתח את השער" — Grok נכנס לקישור סודי והשער נפתח |
| **מכשיר מצומד** | פותחים `/car` בדפדפן הטסלה (או בטלפון), מאשרים קוד בן 6 תווים בפאנל, ומקבלים כפתור ענק. בלי קישורים סודיים |
| **אוטומציה בטלפון** | iOS Shortcuts / Tasker — פתיחה אוטומטית כשמתקרבים הביתה |

## אבטחה

פירוט מלא, כולל הצ'קליסט של 20 הנקודות ותוצאות התקיפה העצמית: [SECURITY.md](SECURITY.md).
בקצרה: סיסמה ואימות דו-שלבי חובה, הצפנת AES-256 לכל מה שרגיש, Rate Limiting של Cloudflare,
CSP קשיח, הרשאה נפרדת לכל דרך פתיחה, מצב "דרוך" ל-Grok, התראות לטלפון ויומן אבטחה.

## הערות
- הפרוטוקול של PalGate אינו רשמי. הוא מבוסס על [pylgate](https://github.com/DonutByte/pylgate) (GPLv3), שהגיע אליו בהנדסה לאחור.
  עדכון של PalGate עלול לשבור אותו. השימוש באחריותך ובהתאם לתנאי השימוש של PalGate.
- היכולת של Grok בטסלה לגלוש לכתובות תלויה בגרסת התוכנה ובחשבון. אם לא עובד — השתמש בכפתור במסך.

## פיתוח
```bash
npm test          # בדיקות: AES מול node:crypto, תעתיק של pylgate, וזרימת השרת מול PalGate מדומה
npm run typecheck
npm run dev       # צריך .dev.vars עם ENC_KEY=... ו-SETUP_CODE=...
```
