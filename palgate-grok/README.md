# 🚗 PalGate × Grok — פתיחת שער בקול מהטסלה

שרת פרטי קטן (Cloudflare Worker, חינמי) שמחבר את חשבון ה-PalGate שלך
ומאפשר לפתוח את השער ב:

| דרך | איך |
|---|---|
| **Grok בטסלה** | "היי Grok, פתח את השער" — Grok נכנס לקישור סודי והשער נפתח |
| **כפתור ענק במסך הרכב** | דף מותאם לדפדפן הטסלה, לחיצה אחת (גיבוי אמין כשה-Grok מתעקש) |
| **אוטומציה בטלפון** | iOS Shortcuts / Tasker — פתיחה אוטומטית כשמתקרבים הביתה |

## למה זה טוב יותר משירות מסחרי
- **השרת שלך** — אף חברה חיצונית לא מחזיקה גישה לשער שלך. בלי מנוי.
- **חיבור כ"מכשיר מקושר"** של PalGate (אותו מנגנון שמיועד למולטימדיה ברכב) — בלי SMS ובלי לנתק את הטלפון.
- **כמה שערים** עם כינויים (`/home`, `/walk`), כולל ממסר 2.
- **הגנות**: השהיה נגד כפילויות (Grok לפעמים טוען פעמיים), מגבלת פתיחות לשעה,
  התעלמות מ"תצוגה מקדימה" של WhatsApp/Telegram (כדי שהדבקת הקישור בצ'אט לא תפתח את השער),
  `no-store`/`noindex`, החלפת קישור סודי בלחיצה.
- **יומן פתיחות** עם מקור (grok / tesla-browser / טלפון).

## התקנה (כ-10 דקות)

דרוש חשבון Cloudflare חינמי ו-Node 20+.

```bash
cd palgate-grok
npm install
npx wrangler login
npx wrangler kv namespace create GATE      # הדבק את ה-id שהודפס ב-wrangler.toml
npx wrangler secret put ADMIN_PASSWORD     # סיסמה לפאנל הניהול
npx wrangler deploy                        # מדפיס כתובת: https://palgate-grok.<you>.workers.dev
```

ואז היכנס ל-`https://palgate-grok.<you>.workers.dev/admin` (משתמש: כל דבר, סיסמה: מה שהגדרת):

1. **חיבור PalGate** — "הצג קוד QR", ובאפליקציית PalGate: ☰ ← מכשירים מקושרים ← קשר מכשיר ← סרוק.
2. **בחירת שערים** — סמן, תן שם וכינוי, שמור, לחץ "בדיקה".
3. **Grok** — העתק את ההוראות המוכנות לאפליקציית Grok ← הגדרות ← Customize (הוראות מותאמות).
   ודא שה-Grok ברכב מחובר לאותו חשבון. ברכב: "היי Grok, פתח את השער".

## כתובות

| כתובת | מה עושה |
|---|---|
| `GET/POST /o/<secret>[/<alias>][/<כל דבר>]` | פותח שער. סיומת אקראית עוקפת מטמון. `?json` מחזיר JSON |
| `GET /car/<secret>` | כפתורים גדולים למסך הרכב |
| `/admin` | פאנל הגדרות (Basic auth) |

## אבטחה — חשוב
הקישור הסודי הוא מפתח: כל מי שמחזיק בו פותח את השער. הוא נשמר בהוראות של Grok
ובהיסטוריית השיחות שלו. אם דלף, לחץ "החלף קישור סודי" בפאנל.
פרטי החיבור ל-PalGate שמורים ב-KV של חשבון ה-Cloudflare שלך בלבד.
לניתוק מלא: "נתק" בפאנל **וגם** הסרת המכשיר באפליקציית PalGate.

## הערות
- הפרוטוקול של PalGate אינו רשמי. הוא מבוסס על [pylgate](https://github.com/DonutByte/pylgate) (GPLv3), שהגיע אליו בהנדסה לאחור.
  עדכון של PalGate עלול לשבור אותו. השימוש באחריותך ובהתאם לתנאי השימוש של PalGate.
- היכולת של Grok בטסלה לגלוש לכתובות תלויה בגרסת התוכנה ובחשבון. אם לא עובד — השתמש בכפתור במסך.
