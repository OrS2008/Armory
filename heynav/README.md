# HeyNav: ניווט לדפדפן של הרכב

אפליקציית ניווט פנייה־אחר־פנייה שרצה בדפדפן (מותאמת לדפדפן של טסלה), כ-Cloudflare Worker נפרד.

**כתובת:** https://heynav.ors2008.workers.dev

## מה יש
- מיקום מדויק מהדפדפן, המפה עוקבת אחרי הרכב ומסתובבת לכיוון הנסיעה (תלת־ממד).
- חיפוש יעד (כתובת או מקום), חישוב מסלול, זמן הגעה ומרחק.
- הנחיות בעברית ובאנגלית, על המסך ובקול: פניות, כיכרות ("צא ביציאה השנייה"), מחלפים, התפצלויות.
- זיהוי יציאה מהמסלול וחישוב מסלול חדש לכיוון הנסיעה.
- בית, עבודה ויעדים אחרונים (נשמרים רק במכשיר).
- נסיעת ניסיון: מדמה נסיעה לאורך המסלול, דרך אותו קוד הנחיות.
- שתי שורות: מוצא (ברירת מחדל: המיקום שלי, או כל כתובת/נקודה במפה) ויעד; הפיכת כיוון.
- עד 3 מסלולים לבחירה: המהיר ביותר (לפי תנועה בזמן אמת) והקצר ביותר.
- מצלמות מהירות ורמזור מהמפה הציבורית של "מיצו בדרכים" (מתעדכן אוטומטית כל 6 שעות), עם התראה רק בכיוון הנסיעה.
- תנועה בזמן אמת (TomTom): שכבת עומסים, תאונות וחסימות על המסלול, ובזמן נסיעה בדיקה כל 4 דקות אם יש מסלול מהיר יותר.
- תצוגת נהיגה נמוכה בסגנון "Reality View": מבט מאחורי הרכב, בניינים בתלת־ממד, אופק ומסלול זוהר; המפה חוזרת לרכב לבד אחרי הזזה.
- מד מהירות (מסומן באדום מעל המהירות המותרת של מצלמה קרובה).
- דיווחי נהגים: משטרה, תאונה, חסימה, מפגע, פקק, מצלמה ניידת. מוצגים לכל המשתמשים, התראה קולית על דיווח בדרך, ושאלת "עדיין שם?" אחרי שעוברים.
- הימנעות מכבישי אגרה ומשטחי A (ערי הרשות הפלסטינית; כניסת ישראלים אסורה בחוק). שטחי A מסומנים במפה.
- הגדרות (⚙): הימנעויות, קול, יום/לילה, עברית/אנגלית.

## איך זה בנוי
| חלק | מקור |
|---|---|
| מפה | MapLibre GL (מוגש מה-Worker), אריחים מ-OpenFreeMap, נתוני © OpenStreetMap |
| מסלולים | OSRM; עם הימנעויות: Valhalla (FOSSGIS). גבולות שטחי A: OpenStreetMap (scripts/area-a.py) |
| דיווחים | Cloudflare KV (`REPORTS`), לפי משבצות של כ-10 ק"מ, עם תפוגה אוטומטית |
| חיפוש | Photon של komoot, וגיבוי Nominatim (דרך ה-Worker) |
| מצלמות | Google My Maps של "מיצו בדרכים" (ייצוא KML, דרך ה-Worker) |
| תנועה | TomTom: זמני נסיעה עם עומסים, שכבת תנועה ותקלות (דרך ה-Worker; המפתח לא מגיע לדפדפן) |

### הפעלת תנועה בזמן אמת
1. נרשמים בחינם ב-developer.tomtom.com ויוצרים מפתח API.
2. ב-Cloudflare: Workers & Pages ← heynav ← Settings ← Variables and Secrets ← Add ← סוג Secret, שם `TOMTOM_KEY`.
בלי המפתח הכול עובד, רק בלי נתוני תנועה.
לישראל TomTom מספק זמני נסיעה לפי עומס אופייני לשעה (לא נתונים חיים); המסך מציין זאת.

ה-Worker מתווך בין הדפדפן לשירותי המסלול והחיפוש: הם לא רואים את כתובת ה-IP של הנהג, ויש הגבלת קצב לכל IP.
אלה שירותים ציבוריים וחינמיים עם מדיניות שימוש הוגן; לשימוש רחב צריך שרת מסלולים משלך (OSRM/Valhalla) או ספק בתשלום.

`src/core.ts` הוא מנוע ההנחיות (גאומטריה, התקדמות, הכרזות, יציאה מהמסלול). אותו קוד נשלח לדפדפן כמו שהוא, כך שהבדיקות בודקות בדיוק את מה שמנחה את הנהג.

## פיתוח
```bash
npm install
npm run assets        # יוצר את src/assets.gen.ts (MapLibre + גופנים)
npm test              # בדיקות יחידה, כולל נסיעה מדומה על מסלולים אמיתיים
npm run deploy
```
בדיקת קצה־לקצה מקומית: `node qa/relay.cjs` ו-`npx wrangler dev --port 8795` (עם `.dev.vars` שמפנה ל-relay), ואז `node qa/e2e.cjs`.

HeyNav אינו קשור ל-Waze, ל-Google או ל-Tesla.
