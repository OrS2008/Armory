# HeyGate

פתיחת שער **PalGate** בקול מ-**Grok בטסלה**, בכפתור ענק במסך הרכב, או אוטומטית בהגעה הביתה.
שירות לכמה לקוחות (multi-tenant) על Cloudflare Workers. לכל לקוח חשבון מבודד ומוצפן משלו.

| דרך | איך |
|---|---|
| 🗣️ **Grok בקול** | "היי Grok, פתח את השער". אפשר לחייב "דריכה" מהטלפון לפני ש-Grok פותח |
| 🚘 **מכשיר מצומד** | פותחים `/car` בדפדפן הטסלה או בטלפון, מאשרים קוד בן 6 תווים, ומקבלים כפתור ענק |
| 📱 **אוטומציה** | iOS Shortcuts / Tasker שולחים POST בהגעה הביתה |

## כתובות

| כתובת | מה |
|---|---|
| `/` | דף הבית |
| `/app` | אזור הלקוח: הרשמה וכניסה עם Passkey, קוד שחזור, ופאנל הניהול |
| `/sa` | מנהל המערכת (אתה): לקוחות, חסימה, מחיקה, פתיחה וסגירה של הרשמה. **בלי גישה לנתוני לקוחות** |
| `/car` | צימוד מכשיר ואחריו כפתורי פתיחה |
| `/o/<secret>[/<alias>]` | קישור פתיחה (Grok: GET; אוטומציה: POST) |
| `/arm/<secret>` | דריכת Grok מאוטומציית הטלפון (POST) |
| `/privacy` | מדיניות פרטיות (טיוטה) |

## בידוד בין לקוחות

- כל לקוח הוא מזהה אקראי. כל הנתונים שלו נשמרים תחת `t:<id>:` ומוצפנים ב-AES-256-GCM,
  **במפתח שנגזר לכל לקוח בנפרד** (HKDF מ-`ENC_KEY`).
- מזהה הלקוח לא מתקבל מהדפדפן אף פעם. הוא נקבע רק מסשן בשרת, מ-Passkey, מעוגיית מכשיר או מסוד קישור,
  דרך אינדקסים ששומרים **גיבוב בלבד**.
- נבדק בבדיקות אוטומטיות: לקוח לא רואה, לא משנה ולא פותח את מה ששייך ללקוח אחר.
  מכשיר שצומד אצל לקוח אחד שייך רק לו, ומפתח של לקוח אחד לא פותח נתונים של לקוח אחר.

## התקנה

```bash
cd heygate && npm install
npx wrangler login
npx wrangler kv namespace create HEYGATE                    # הדבק את ה-id ב-wrangler.toml
python3 -c 'import secrets,base64;print(base64.urlsafe_b64encode(secrets.token_bytes(32)).decode().rstrip("="))' | npx wrangler secret put ENC_KEY
npx wrangler secret put SETUP_CODE                         # קוד חד-פעמי ליצירת מנהל המערכת
npx wrangler deploy
```

אחר כך נכנסים ל-`/sa`, מזינים את קוד ההתקנה ויוצרים Passkey של מנהל. לקוחות נרשמים בעצמם ב-`/app`.

> ⚠️ **מכסות:** בתוכנית החינמית של Cloudflare יש 1,000 כתיבות KV ביום. פתיחה צורכת כ-5 כתיבות,
> כך שכמה לקוחות פעילים יגיעו למכסה מהר. ללקוחות אמיתיים כדאי Workers Paid ($5 לחודש).

## אבטחה

פירוט מלא ב-[SECURITY.md](SECURITY.md): Passkey בלבד, בידוד והצפנה לכל לקוח, Rate Limiting,
CSP קשיח, מצב "דרוך" ל-Grok, התראות לטלפון, יומן, ותקיפה עצמית.

## הערות
- הפרוטוקול של PalGate אינו רשמי. הוא מבוסס על [pylgate](https://github.com/DonutByte/pylgate) (GPLv3).
  הפעלת שירות מסחרי מעל PalGate עשויה לדרוש אישור מהם. יש לבדוק את תנאי השימוש.
- שמירת מספרי טלפון ואסימוני גישה של לקוחות הופכת אותך ל"בעל מאגר". כדאי לבדוק עם עורך דין
  את מדיניות הפרטיות ואת דרישות חוק הגנת הפרטיות.
- לפני שימוש מסחרי בשם HeyGate, כדאי לבדוק שאין סימן מסחר רשום.
