## תוצאות התקיפה העצמית (40 תרחישים)

כל הניסיונות נכשלו כמצופה:
- **עקיפת התחברות:** API בלי סשן או עם עוגייה מזויפת, GET במקום POST, ותעלולי נתיב
  (`/ADMIN`, `//admin`, `..`, `%2f`).
- **CSRF:** בלי כותרת ייעודית, עם Origin זר, עם `Origin: null`. אין CORS ל-Origin זר.
- **השתלטות:** הרצת ההתקנה מחדש אחרי שכבר הוגדר חשבון.
- **קלט זדוני:** JSON שבור, גוף של 100KB, prototype pollution (`__proto__`),
  XSS שמור בשם שער או גישה (מוצג מקודד), ומזהי נתיב (`../../etc`).
- **ניחוש:** ניחוש קישורים (IP נחסם אחרי 20), ניסיונות כניסה כושלים (נעילה גם עם Passkey תקף).
- **Passkey:** שימוש חוזר בתשובה חתומה (האתגר נשרף), חתימה לאתר פישינג דומה (origin שגוי),
  חתימה במפתח זר, מכשיר שדילג על Face ID, ומכשיר של מישהו אחר. כולם נדחו.
  נבדק עם מאמת תוכנה שמייצר בתים אמיתיים של WebAuthn, וגם בדפדפן אמיתי עם מאמת וירטואלי.
- **צימוד:** בדיקת קוד מדפדפן אחר (נדחה), פתיחה בלי עוגיית מכשיר (נדחה), קוד חד-פעמי.
- **כותרות:** CSP קשיח, HSTS, DENY ו-nosniff בכל סוגי התגובות.

## מגבלות ידועות (ביושר)

1. **קישור Grok הוא סוד-נושא.** Grok יודע רק "לבקר" בכתובת. מי שרואה את
   ההוראות (למשל בחשבון ה-Grok) יכול לפתוח. ההגנות: מצב "דרוך", התראות,
   מגבלה שעתית, והחלפת קישור בלחיצה.
2. **מוני ה-KV הם בעקביות-בסוף.** בהתקפה מבוזרת מאוד אפשר לעבור מעט את הספים
   לפני שהם מתעדכנים. ה-Rate Limiter של Cloudflare וה-TOTP מכסים את הפער.
3. **המכסה החינמית של Cloudflare KV היא 1,000 כתיבות ביום.** פתיחה רגילה כותבת
   כ-5 פעמים. פעולות שאינן קריטיות (מונים, יומן) עטופות, כך שחריגה ממכסה לא
   מונעת פתיחה.
4. **הפרוטוקול של PalGate לא רשמי** ועלול להשתנות.

## שחזור גישה

ה-Passkey מסונכרן ל-iCloud Keychain או ל-Google Password Manager, כך שהחלפת טלפון לא מאבדת אותו.
מומלץ להוסיף Passkey למכשיר נוסף (אבטחה ← הוסף מכשיר).
אם בכל זאת אבדה כל הגישה: מוחקים את `admin` מה-KV
(`npx wrangler kv key delete --binding GATE --remote admin`), מגדירים `SETUP_CODE` חדש ויוצרים Passkey מחדש.
החיבור ל-PalGate, השערים והגישות נשמרים.

## הוספת Cloudflare Access (מומלץ, 5 דקות)

1. dash.cloudflare.com ← **Zero Trust** (חינם עד 50 משתמשים) ← בחר שם צוות.
2. Access ← Applications ← **Add** ← Self-hosted:
   - Domain: `palgate-grok.<you>.workers.dev`, Path: `admin`
   - Policy: Allow ← Emails ← המייל שלך (התחברות בקוד חד-פעמי למייל או Google).
3. העתק את **Application Audience (AUD) Tag**.
4. `npx wrangler secret put ACCESS_TEAM_DOMAIN` (למשל `myteam.cloudflareaccess.com`)
   ו-`npx wrangler secret put ACCESS_AUD`.

מעכשיו `/admin` דורש שלוש שכבות: Access, סיסמה ו-TOTP. הקישורים ל-Grok,
למכשירים ולאוטומציות לא מושפעים.
