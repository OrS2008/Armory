# 🚗 PalGate × Grok — פתיחת שער בקול מהטסלה

שרת פרטי קטן (Cloudflare Worker, חינמי) שמחבר את חשבון ה-PalGate שלך
ומאפשר לפתוח את השער ב:

| דרך | איך |
|---|---|
| **Grok בטסלה** | "היי Grok, פתח את השער" — Grok נכנס לקישור סודי והשער נפתח |
| **כפתור ענק במסך הרכב** | דף מותאם לדפדפן הטסלה, לחיצה אחת (גיבוי אמין כשה-Grok מתעקש) |
| **אוטומציה בטלפון** | iOS Shortcuts / Tasker — פתיחה אוטומטית כשמתקרבים הביתה |

## אבטחה

| שכבה | מה יש |
|---|---|
| **כניסה לפאנל** | סיסמה (PBKDF2-SHA256, 100K איטרציות) + **אימות דו-שלבי חובה** (TOTP — Google/Microsoft Authenticator, Authy, 1Password). קוד חד-פעמי, לא ניתן לשימוש חוזר |
| **ניחוש סיסמה** | נעילה אחרי 5 כישלונות ל-IP ל-15 דק׳, ותקרה גלובלית של 30 כישלונות לשעה נגד התקפה מבוזרת |
| **סשן** | עוגייה `__Host-` עם HttpOnly + Secure + SameSite=Strict, 12 שעות. "נתק את כל המכשירים", והחלפת סיסמה מנתקת את כל השאר |
| **CSRF** | שלוש שכבות: SameSite=Strict, בדיקת Origin וכותרת ייעודית |
| **הצפנה במנוחה** | כל מה שרגיש (מפתח PalGate, קישורים, 2FA, יומן) מוצפן ב-AES-256-GCM, קשור לשם המפתח. מפתח ההצפנה הוא Secret של Cloudflare שלא נחשף לאף אחד |
| **דפדפן** | CSP קשיח עם nonce (אין הרצת סקריפט מוזרק), HSTS, איסור הטמעה במסגרת, nosniff, no-referrer, Permissions-Policy |
| **קישורי פתיחה** | קישור נפרד לכל ערוץ (Grok / רכב / טלפון), 192 ביט. כל אחד ניתן להשבתה, להחלפה, להגבלת מדינה ולמגבלת פתיחות לשעה בנפרד |
| **רכב וטלפון** | עובדים רק ב-POST וכברירת מחדל רק מישראל, כך שקדם-טעינה, תצוגה מקדימה או לחיצה אקראית לא יפתחו |
| **ניחוש קישורים** | IP שניחש 20 קישורים שגויים בשעה נחסם לגמרי |
| **מתג חירום** | השבתה מיידית של כל הפתיחות בלחיצה |
| **זיהוי** | התראות לטלפון (ntfy) על כל פתיחה, ניסיון חסום והתחברות, ויומן אבטחה מוצפן עם IP ומדינה |
| **התקנה ראשונה** | קוד התקנה חד-פעמי. אחרי יצירת החשבון הוא מפסיק לעבוד |

**מגבלה שאי אפשר לעקוף:** Grok יכול רק "לבקר" בקישור, ולכן קישור ה-Grok הוא סוד-נושא (bearer).
מי שרואה אותו (למשל בהיסטוריית Grok) יכול לפתוח. ההגנות: התראה מיידית, מגבלה לשעה, והחלפה בלחיצה.
הערוצים המאובטחים ביותר הם הכפתור ברכב והאוטומציה בטלפון (POST + הגבלת מדינה).

**שחזור** (אם איבדת את אפליקציית האימות): מוחקים את המפתח `admin` מה-KV
(`npx wrangler kv key delete --binding GATE --remote admin`), מגדירים `SETUP_CODE` חדש, ומבצעים התקנה מחדש.
החיבור ל-PalGate והקישורים נשמרים.

## הערות
- הפרוטוקול של PalGate אינו רשמי. הוא מבוסס על [pylgate](https://github.com/DonutByte/pylgate) (GPLv3), שהגיע אליו בהנדסה לאחור.
  עדכון של PalGate עלול לשבור אותו. השימוש באחריותך ובהתאם לתנאי השימוש של PalGate.
- היכולת של Grok בטסלה לגלוש לכתובות תלויה בגרסת התוכנה ובחשבון. אם לא עובד — השתמש בכפתור במסך.

## פיתוח
```bash
npm test          # בדיקות: AES מול node:crypto, תעתיק של pylgate, וזרימת השרת מול PalGate מדומה
npm run typecheck
npm run dev       # צריך .dev.vars עם ENC_KEY=... ו-SETUP_CODE=...
```
